# Data folder

This folder must contain the input files listed below before running the
analysis scripts. The folder ships almost empty in the GitHub repository.

## How to populate this folder

| File | Size | Source | Action |
|---|---|---|---|
| `hp.obo` | ~10 MB | HPO consortium (public) | Run `python scripts/download_public_data.py`, or `main.py` will fetch it on first run |
| `hpo_terms_to_classify.csv` | small | Provided | Already in repo root; `main.py` moves it here on first run |
| `hyperparameter_results.csv` | ~5 KB | Provided | Already in this folder |
| `GT_file.xlsx` | ~60 KB | Provided | Already in this folder |
| `MM_with_Severity.csv` | ~219 KB | Provided | Already in this folder |
| `CS.xlsx` | ~14 KB | Provided | Already in this folder |
| `SF.xlsx` | ~17 KB | Provided | Already in this folder |
| `Classified_terms.csv` | ~69 MB | **Generated by `main.py`** OR request from corresponding author | Run `python main.py`, or place file here |
| `final_merged_output_with_freq.pkl` | ~25 MB | Provided | Already in this folder |

## File roles in the pipeline

```
main.py                       → produces Classified_terms.csv
hyperparameter.py             ← reads hyperparameter_results.csv
visualization.py              ← reads Classified_terms.csv + GT_file.xlsx
severity_classification.py    ← reads final_merged_output_with_freq.pkl,
                                MM_with_Severity.csv, CS.xlsx, SF.xlsx
```
